# APB-config-manager

// Automatically fetch Flaw's latest cfg files and save selection to automate file replacement.

A Windows desktop app that downloads and installs selected components from Flaw’s APB Reloaded Config.

Unofficial community tool. Not affiliated with Little Orbit, GamersFirst, or Flaw.

What it does

Checks Flaw’s latest GitHub release.

Downloads the selected config ZIP.

Lets you choose config features and localization add-ons.

Installs selected files into your chosen APB Reloaded folder.

Shows a preview and asks before replacing existing files.

Remembers your selected options for future releases.

Download and run

Download APBConfigManager.exe from this repository’s Releases page.

Run the EXE.

Click Choose APB Game Folder and select the main APB Reloaded folder—the folder containing APBGame.

Click Check for Config Updates.

Click Download and Inspect Config.

Select the config features you want.

Click Preview Changes, then Install Selected.
